Core Features

Built for ODD-Compliant Orchestration

Every feature is designed around Organic Driven Development principles: delegate by named reason, spec by reference, verify proportional to risk.

Planner → Implementer → Verifier Chain

Full orchestration cycle with CHANGES retry loop (max 3 attempts). Each role has strict permissions enforced at the protocol level.

Native gentle-shell Review Integration

Phase 2 verification uses review.start/review.finalize with lenses review-readability + review-reliability for ODD S1/S2 requirements.

Blackboard Persistence (Phase 4)

TaskContract state survives daemon restarts. Every transition (pending → in_progress → completed/failed) persisted to shared JSON state file.

Zero-Trust Security (Phase 5/6)

Per-role permissions (Planner, Implementer, Worker, Verifier), mTLS, audit logging, rate limiting, secure erasure, allowlist validation.

Invisible Delegation (Phase 3)

Tool-call hook intercepts delegations with named reason, applies role orchestration instead of native delegation. No reason = native proceeds untouched.

Native Background Jobs (Phase 5)

Dogfood via bash_background for master/worker orchestration. Container-ready with SSH tunnel provisioning.

Available Commands

Orchestration at Your Fingertips

Five slash commands registered in Pi. All output via TUI notifications for seamless workflow integration.

/coworkShow orchestration status — last contract, role, and state
/cowork-contractDisplay the last TaskContract as JSON
/cowork-verifyPhase 1: spawn cowork-verifier subagent via native review integration
/cowork-chainPhase 2: run full planner → implementer → verifier chain with test objective
/cowork-dogfoodPhase 5: run native background jobs (master/worker) via bash_background
Installation

Install in Seconds

Install globally for all projects, or locally for a specific project. Both methods register the extension and its commands automatically.

$ pi install npm:gentle-cowork@1.2.2

Installs to ~/.pi/agent/settings.json. Available in all projects immediately.

$ pi install npm:gentle-cowork@1.2.2 -l

Writes to .pi/settings.json in current project. Requires project_trust grant.

$ pi install git:github.com/ipproyectosysoluciones/gentle-cowork@v1.2.2

Installs directly from GitHub tag. Useful for testing pre-release changes.
